# CleanOS

CleanOS turns macOS performance work into a measured workflow: baseline, isolate, propose reversible changes, and prove the gain with before/after evidence.

## Status

Public MIT scaffold under active SSSF INTAKE/SCOUT. Product code comes after typed envelopes, write boundaries, and deterministic gates land.

## Principles

- Measure before mutation.
- Prefer reversible, identity-safe changes.
- Keep secrets and machine identity out of published artifacts.
- Ship claims only when matched evidence backs them.

## Development

Canonical loop: `INTAKE → SCOUT → PLAN → BUILD → VALIDATE → REVIEW → SHIP`.
